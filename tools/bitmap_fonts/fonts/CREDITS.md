## Pixelify Sans  →  `pixelify_r11.bdf`
- **Designer:** Stefie Justprince
- **License:** SIL Open Font License 1.1 (OFL)
- **Source:** https://fonts.google.com/specimen/Pixelify+Sans
- **Upstream repo:** https://github.com/eifetx/Pixelify-Sans

`pixelify_r11.bdf` is a 1-bit bitmap derived from Pixelify Sans Regular by
snapping its outlines to the font's native ~11-design-pixel/em grid (cap height
7px, x-height 5px), using `import-from-vector.html`. The OFL permits this
modification and redistribution; it remains under the OFL. If you ship a badge
build, keep this credit and the OFL notice with the font.

When adding a new font here, record its designer, license, and source URL in
this file.
