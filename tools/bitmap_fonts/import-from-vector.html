Pixel Font Baker

Drop a vector pixel font → it auto-detects the native pixel grid, snaps each glyph to a true 1-bit bitmap, and exports a .bdf you then open in editor.html. No build step, no dependencies.

1 · Load the font

Drop a .ttf / .otf / .woff here, or click to pick.

2 · Grid & snap

Snapped preview —

Each square is one bitmap pixel (nearest-neighbour at the zoom above). This is exactly what LVGL blits — 1 design-pixel → 1 screen pixel.

3 · "Clean size" advisor — the simpler raw-TTF path

If you skip snapping and bake the raw TTF, these --size values land one design-pixel on whole screen pixels (so --bpp 1 stays uniform). Highlighted rows are integer multiples of the detected grid.

4 · Export

32–126 = printable ASCII.

Save the .bdf into your fonts/ folder, then open editor.html to tweak glyphs and Export .bin (LVGL). The editor writes the .bin directly from the bitmap — no lv_font_conv, no TTF roundtrip (which we proved distorts bearings; see README.md).
